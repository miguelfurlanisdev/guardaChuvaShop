# ☂️ Guarda-Tudo Shop

**Você não é de açúcar.**

Loja de guarda-chuvas com funcionalidades absurdas, criada para um projeto escolar de Desenvolvimento de Sistemas no SENAI.

## 🛒 Sobre o projeto

A Guarda-Tudo Shop é uma loja que transforma situações cotidianas em produtos inusitados. A ideia é criar guarda-chuvas com funcionalidades exageradas, inúteis e, ao mesmo tempo, surpreendentes.

O projeto foi desenvolvido como uma atividade proposta pelo professor, com o objetivo de praticar desenvolvimento web e criar uma identidade visual própria para uma loja virtual.

## 💡 Identidade visual

- **Nome:** Guarda-Tudo Shop
- **Slogan:** Você não é de açúcar.
- **Proposta:** Guarda-chuvas com funcionalidades absurdas. Diferente de você...
- **Estilo:** Visual moderno, divertido e futurista.
- **Cores principais:** Preto, laranja e branco.

## 🚀 Funcionalidades do site

- Página inicial com apresentação da loja.
- Catálogo de guarda-chuvas com funcionalidades absurdas.
- Cards de produtos com imagens, descrições e preços fictícios.
- Botões de compra e navegação entre páginas.
- Página sobre a empresa, com sua história fictícia.
- Página de contato.
- Layout responsivo para computadores e celulares.
- Efeitos visuais e interações com CSS.

## 🛍️ Produtos

O catálogo apresenta produtos criativos e exagerados, como:

- Guarda-Chuva Móvel: protege você e seu carro da chuva.
- Guarda-Chuva Chuveiro: permite tomar banho enquanto se protege da chuva.
- Guarda-Chuva Foguete: permite decolar e fugir da chuva.
- Guarda-Chuva Perfomático: um modelo com design diferenciado.
- Outros produtos com funcionalidades absurdas e preços fictícios.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura e organização das páginas |
| CSS3 | Estilização, identidade visual e efeitos |
| Bootstrap | Componentes, cards, botões e layout responsivo |

## 📋 Requisitos do projeto

O site foi desenvolvido com base nos requisitos mínimos propostos pelo professor:

- Estrutura semântica em HTML5.
- Estilização com CSS3, incluindo cores, tipografia, espaçamento e efeitos de hover.
- Utilização de Flexbox ou Grid.
- Bootstrap com navbar responsiva, cards, botões, grid e componente adicional.
- Seções ou páginas de início, produtos, sobre a empresa e contato.
- Catálogo com pelo menos seis produtos, imagens, descrições e preços fictícios.
- Responsividade para computadores e celulares.
- Identidade visual própria, incluindo nome, slogan e logotipo.
- Promoção absurda para os produtos da loja.

## 🎯 Objetivo

Praticar os fundamentos do desenvolvimento web, aplicando HTML5, CSS3 e Bootstrap na criação de uma loja virtual fictícia, com identidade visual própria, criatividade e organização de código.
