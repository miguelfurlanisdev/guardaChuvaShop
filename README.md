# Guarda-Tudo Shop

**Slogan:** Guarda-chuvas com funcionalidades absurdas.

Site de uma loja fictícia de guarda-chuvas, feito para a disciplina de desenvolvimento web (tema 17: "Guarda-Chuva Furado").

## Páginas

- `index.html`: início (hero, carrossel de destaques, origem, significado, fundadora, promoção)
- `pages/produtos.html`: catálogo com 6 produtos, imagens, descrições e preços fictícios
- `pages/sobre.html`: história, missão/visão/valores e FAQ (accordion)
- `pages/vender.html`: promoção absurda "Chove, Você Ganha!" (cupom `CHOVEU30`)
- `pages/contato.html`: formulário e dados de contato

## Requisitos atendidos

- **HTML5:** tags semânticas (`header`, `nav`, `main`, `section`, `article`, `footer`, `address`), títulos, parágrafos, imagens com `alt`, links e formulário.
- **CSS3:** variáveis de cor, tipografia, espaçamento, Flexbox/Grid e efeitos de hover (`style/style.css`).
- **Bootstrap 5:** navbar responsiva, cards, botões, grid, carrossel e accordion.
- **Identidade visual:** nome, slogan, logotipo (`img/logo.svg`) e promoção absurda.
- **Responsividade:** layout adaptado para computador e celular.

## Como rodar

Abra `index.html` no navegador (é necessário internet para carregar o Bootstrap via CDN).
